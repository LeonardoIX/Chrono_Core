Chrono_Core

Chrono_Core é um jogo de plataforma 2D desenvolvido na Unity, ambientado em um cenário de ficção científica. O projeto busca explorar mecânicas clássicas de plataforma combinadas com elementos temáticos futuristas e foco em jogabilidade fluida.

Tecnologias utilizadas

O desenvolvimento do jogo utiliza:

Unity, como motor principal.

C#, como linguagem de programação para scripts e lógica do jogo.

Como executar o projeto

Atualmente, o projeto só pode ser executado diretamente pela Unity.

1. Instalar a Unity

É necessário ter o Unity Hub instalado. A versão exata da Unity utilizada pelo projeto será detectada automaticamente quando o repositório for aberto pelo Unity Hub, mas é recomendável manter versões recentes instaladas para evitar incompatibilidades.

2. Baixar o repositório

O repositório pode ser obtido por meio do comando:

git clone https://github.com/seu-usuario/Chrono_Core.git


ou por download direto no GitHub através da opção “Download ZIP”.

3. Abrir o projeto na Unity

Para abrir o projeto:

Abra o Unity Hub.

Acesse a aba “Projects” e selecione a opção “Open”.

Escolha a pasta onde o repositório se encontra.

A Unity carregará o projeto e ajustará automaticamente a versão necessária.

As cenas estão localizadas na pasta “Assets”; basta selecionar a cena desejada.

Após abrir a cena, utilize o botão “Play” para executar o jogo dentro do editor.

Funcionalidades principais

O projeto inclui as seguintes funcionalidades:

Mecânicas básicas de movimentação em plataforma 2D.

Ambientação futurista baseada em elementos de ficção científica.

Implementação de inimigos, obstáculos e interações típicas do gênero.

Sistema de transição entre cenas e fases.

Organização do código em scripts C# integrados ao motor Unity

Requisitos de hardware mínimos
Sistema Operacional:
Windows: Windows 7 SP1+, Windows 10 ou Windows 11 (versões de 64 bits)
macOS: High Sierra 10.13+
Processador:
Arquitetura x64 com conjunto de instruções SSE2
Memória RAM:
Mínimo: 4 GB
Recomendado: 8 GB
Placa de Vídeo:
Windows: GPUs compatíveis com DX10, DX11 e DX12
macOS: GPUs compatíveis com a tecnologia Metal
Armazenamento:
Um disco de estado sólido (SSD) é recomendado.
